# ⚡ Voltag Gym — Landing Page (SEO & AI Discovery)

[![Ver en vivo](https://img.shields.io/badge/Demo_en_Vivo-voltag--landing.vercel.app-10B981?style=for-the-badge&logo=vercel&logoColor=white)](https://voltag-landing.vercel.app)

Landing page oficial desarrollada por **Juan Miguel Guerrero ([MagnusCode](https://github.com/juanpps))** para **Voltag Gym**.

## 🎯 Qué problema resuelve
Diseñada específicamente con optimización técnica para buscadores tradicionales (**SEO**) y motores de respuesta basados en IA (**GEO / AI Discovery**), logrando que el gimnasio pasara de estar oculto a recibir clientes nuevos por recomendación directa.

## 🛠️ Stack Tecnológico
- **Framework:** Astro + React
- **Estilos:** Tailwind CSS
- **Backend / Servicios:** Firebase
- **Despliegue:** Vercel (@astrojs/vercel + @astrojs/sitemap)
